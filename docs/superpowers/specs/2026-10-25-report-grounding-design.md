# C/E 正文合同与数字归因诊断

已保存开发 E02 报告把“分割模型优于基线40%”“Transformer基准0.70”归给分割论文，但该自建PDF只报告召回有所改善，没有这些数值。旧自检只查引用形式。另已确认 C/E 构造器和生成解析都对包含参考文献的全文计800字符，短正文可被长参考文献填满。

本轮选择不新增模型调用，先解决可独立复现的问题：统一正文计数字符（参考文献不计入），并对有引用、明确报告论文数值的句子做源文数字缺口诊断。相比增加一轮全文LLM裁判，此方案不占额外模型时间；相比只改提示词，它有确定性回归。后续证据包跨页选取、动态任务覆盖和语义审查仍需单独推进。

数值诊断只对明显论文结果/实测/基准归因检查，使用该句实际引用的授权PDF全文与元数据，不允许其他论文的数字替它作证。兼容百分数/小数以及常见中英文百分数写法；引用编号与参考文献本身不算事实数值。预设目标、计划样本量、待验证阈值、题目模拟观察须与论文实测区分，不能因此触发误诊。

诊断名为 unverified_numeric_attribution，仅表示在所引源文未找到对应数值，不能证明所有数字一致就意味着语义支持。提示模型核对、删去无据数值或明确改为待验证设计。复用现有一次修复及采纳闸，修复稿的引文和数字诊断都不得退化；修复失败仍保留合法初稿。无需新依赖和额外模型调用。
