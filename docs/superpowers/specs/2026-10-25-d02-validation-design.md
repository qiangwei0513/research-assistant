# D-02 生成结果独立校验设计

用户长期目标为正确率和得分优先。旧平台 D-02 为 10/40，但没有本轮源码和隐藏裁判理由，不能认定特定算法错误已在平台发生。

独立审查已通过变异证实：当前校验可放过空预测、编造开发指标和全零排名。采用从公开输入与输出独立重算的局部校验，而不是相信模型自报指标，也不在镜像内预置完整 BM25 算法。

新增 `reproduction/d02_validation.py`：规范化官方三种查询排名表示与两种行表示；检查必需查询、全部文档恰好一次、有限分数、稳定排序；用公开 dev relevant 重算普通/各组/宏/最差组指标；检查全网格唯一覆盖与完整六项选参顺序。只验证公开开发指标，不生成官方最终测试指标。

后续以小型变形输入验证重复查询词、标题权重、未知词与固定 selected 的 run/rank 一致性，不将完整参考检索算法放入 src。独立完整参考算法如需用于开发验证，只能在 scripts 下并排除出镜像。

保持来源要求：所有提交源码仍来自本题 Gateway 完整回复，校验失败只能完整重生成，不能本地修补。新增校验应接受官方等价表示，避免假失败耗尽预算。
