# C/E 参考条目修复与分层采纳

新镜像C01保存报告在正文引用[4]，但引用表仅有[1]至[3]且均与给定材料编号一致。模型修复问题总数仍为1，旧条件拒绝，候选问题类型没有日志，不能判断是否修复了合法性却残留分布问题。

选择两层修复：先确定性补齐可唯一对应的参考条目，再用现有一次模型修复处理内容/分布。相比整篇重写，补条目保持原正文与编号不变，省调用且不引入新事实；相比强行把所有引用映射到材料清单，严格要求已有引用表有至少一个可核验锚点，所有既有条目均唯一、授权且与清单编号一致，正文编号全部在范围内。存在歧义即原样交给模型，不猜测重编号。仅追加缺失条目的完整文件名。

修复采纳使用可解释优先序：来源/引用合法性问题数，实际正文引用的授权材料覆盖，分布/打包/上下文等其余问题数。数字归因诊断不得增加，Idea内容自检不得退化；Survey不得扩大必需材料覆盖缺口。满足非退化门槛后，至少一项有实质改善才采纳。这是本项目修复策略，不是官方分数计算或语义证明。

初稿和候选都先经过相同确定性补条目与全文分析。日志记录前后问题类型、优先序、覆盖与具体接受/拒绝原因；不记录凭据。预算及失败回退沿用现有规则，不新增模型调用轮数。
