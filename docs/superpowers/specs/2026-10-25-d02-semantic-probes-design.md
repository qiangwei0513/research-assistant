# D-02 语义性质与 run/rank 一致性自测

上一阶段的新校验已能验证覆盖、开发指标和选参，却仍可接受自洽的全零排名。本阶段落实原设计中尚未完成的语义检查，提高锁源前发现真实算法错误的概率。

采用少量手算小输入与输出性质检查，不在 src 实现 BM25，不生成正式指标。相比预置完整算法做差分，此方案保持镜像不含完整实现的来源约束；相比只检查排序字段，它能验证实际词频、标题权重和长度归一化行为。

新增五个 rank 探针：重复查询词及空/未知查询；标题权重0与2；正文长度差异下 b=0 与 b=1。检查预期次序、正分/零分、少量可手算分数比，允许每个结果整体正比例缩放和官方等价排名表示。比例比较采用相对误差1e-7，不把固定绝对分数写成标准答案。

每个通过的公开 run 自测追加同语料 rank 重放，分别使用 protocol.default_config 与 details.selected，比较排名文档顺序。不读测试相关性标注，不改变生成源码；诚实基线仅重放默认配置。动态追加仍共享原有12秒整批墙钟预算，不给每个派生用例重领时间。

只在当前 layered-d-v3 的 D-02 材料中启用；不对其他 D 题注入此类输入。所有提交实现仍只能来自本题 Gateway 完整响应，失败只能完整重生成。探针不能证明任意输入下算法正确，后续仍需公开样例/真实生成/平台复评。
